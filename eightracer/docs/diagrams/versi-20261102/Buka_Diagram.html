Buka dan edit

File draw.io · 6 halamanFile Enterprise Architect · 6 diagram27 skenario lengkapKamus data

Buka salinan model di draw.io online. Isi model dibuka di diagrams.net; gunakan file lokal bila ingin bekerja secara lokal.

  1. draw.io: buka file .drawio, kemudian pilih salah satu dari enam tab. Semua objek dan konektor dapat diedit.
  2. Enterprise Architect: buka file .qea. Pada Browser, buka root Eightracer, pilih paket, lalu klik dua kali diagram. Skenario normal/alternatif juga tersimpan pada elemen use case.
  3. Antigravity: file .drawio dapat dibuka dari folder dokumentasi proyek dengan editor draw.io yang sudah tersedia. File EA dibuka dengan Enterprise Architect.

File QEA sudah berhasil dibuka di Enterprise Architect pada laptop ini. Gaya tampilan EA dapat mengikuti tema aplikasi; preview SVG dan draw.io menggunakan latar putih dan garis hitam. Untuk pengaturan tampilan native, tersedia panduan tema resmi EA.

Yang sudah disesuaikan

  • 27 use case dengan 54 skenario utama/alternatif; ID UC01–UC25 dipertahankan. Impor sumber sekolah dan referensi mendapat UC26–UC27.
  • Login Google/OTP, peran, batas sesi admin, pemulihan password dan akses data pemilik.
  • Pemisahan sumber sekolah, asesmen formal, prestasi menunggu tinjauan, penerimaan PT dan progres beasiswa.
  • AI beasiswa: backend menghitung; Gemini menjelaskan; admin meninjau; siswa membaca hasil sendiri yang disetujui.
  • Privasi publikasi alumni, izin finansial dan ringkasan agregat minimal lima alumni berizin.
  • ERD mencakup seluruh tabel aktual. Class memakai 48 model dan 14 layanan dari kode Laravel, beserta metode aktual.

Catatan perubahan dan hal yang masih perlu dilengkapi · Hasil pemeriksaan diagram

Data baru memperkaya profil dan riwayat sekolah. Rekomendasi beasiswa tetap memerlukan katalog resmi, kriteria, dan data profil yang cukup. Catatan penerimaan PT tidak otomatis berarti menerima beasiswa. Revisi diagram ini tidak mengubah status data atau menjalankan publikasi.
